---------------------------------------------------------------------
 1. LE PROJET
---------------------------------------------------------------------
Jeu de deck-building (d'après le PDF du projet) : on joue des cartes contre sa
propre dépression.
- Ambiance Buckshot Roulette / PSX / VHS : une étudiante fait face à une version
  grise et abîmée d'elle-même, dans une pièce sale éclairée par une seule lampe.
- Vue à la première personne : on voit nos mains qui tiennent un éventail de cartes.
- Mécaniques copiées de Slay the Spire : dégâts / bouclier, énergie par tour,
  coût des cartes, Force / Faiblesse / Vulnérable, Crises (cartes parasites).
- Manches = bougies (3 chacune) ; perdre une manche éteint une bougie.
- Monnaie : gouttes de sang ; boutique entre les manches (cartes, reliques,
  consommables, faire évoluer / brûler / transformer une carte).
- Menu des règles, options, pause, crédits ; HUD minimal.


---------------------------------------------------------------------
 2. COMMENT CONSTRUIRE LE JEU
---------------------------------------------------------------------
Tout est généré par un script éditeur :
   Menu Unity > « Lucidité > Construire le jeu »
(Editor/LuciditeSetup.cs, fonction BuildAll). Il crée textures, meshes, prefabs,
UI, données (cartes, actions de la Dépression, objets, GameConfig), le
VolumeProfile et la scène. À relancer après chaque modification des scripts
Editor (PrefabFactory, DataFactory, UIFactory, ThirdParty*...).

Assets tiers (à mettre dans Documents/AssetsUnity, ils sont copiés
automatiquement dans Assets/Lucidite/ThirdParty) :
- psx maiden (Sketchfab, CC-BY 4.0, petya-petyavich) : la Dépression.
  Nécessite le package glTFast (com.unity.cloud.gltfast, déjà dans manifest.json).
- PSX FPS Hands (CC0, NiKo Gillsky) : bras de la joueuse (dossier FPS_Psx_Hands).
- Quaternius Furniture Pack (CC0), Apfelgarten Chairs & Tables PSX (CC0).
- Polices : IM Fell English SC, Special Elite, VT323.
Les choix d'assets sont dans Editor/ImportChoices.cs (useMaiden, useFpsHands...).
Le dossier _FEEDBACK/ contient les captures d'écran envoyées à Claude
(et 18hndcard.jpg : référence de prise des cartes par la main).

Remarque : sur le premier PC, Unity tournait en administrateur, donc Claude ne
pouvait pas piloter Unity ; il compilait les scripts hors Unity (dotnet build
d'un .csproj temporaire) et l'utilisateur lançait « Construire le jeu » puis
envoyait des captures dans _FEEDBACK.
